**Q1: To display all books**

```sql
from "Books"
```

**Q2: To display books priced above 40**

```sql
from "Books"
where Price > 40
```

**Q3: To search books using ID**

```sql
from "Books"
where id() = "books/1-A"
```

**Q4: To search books by title**

```sql
from "Books"
where Title = "Clean Code"
```

**Q5: To display books sorted by price in descending order**

```sql
from "Books"
order by Price desc
```

**Q6: To display books sorted by price in ascending order**

```sql
from "Books"
order by Price
```

**Q7: To display books with stock greater than 10**

```sql
from "Books"
where Stock > 10
```

**Q8: To display books with stock less than 10**

```sql
from "Books"
where Stock < 10
```

**Q9: To display all orders**

```sql
from "Orders"
```

**Q10: To search orders by customer email**

```sql
from "Orders"
where CustomerEmail = "test@example.com"
```
